Navigation

A spec file and the Java code that runs it stay connected. The plugin knows which Java code belongs to each element in the spec file, so you can jump straight to it. Almost every element has somewhere to go: the feature, the rules, the scenarios, the background, the steps, the values in a step, the tags, and the cells of an Examples table.

Navigation also works in the opposite direction, from the Java code back to the spec file. Thus you can move between the spec file and the code with one gesture.

From the spec file to the code​

Press Cmd+Click or Ctrl+Click on almost all elements in a spec file. The IDE opens the related Java code.

In the spec fileThe IDE opens
Feature: keyword, title or description
(aliases: Ability:, Business Need:)		the generated test class
Rule:its @Nested class
Scenario:
(alias: Example:)		the @Test method
Scenario Outline:
(alias: Scenario Template:)		the @ParameterizedTest method
Background:the generated @BeforeEach method, for the feature or for the rule
A step, or its keywordthe step method implementation, or its declaration if it is not implemented yet
A value in quotation marks in a stepthe related parameter of the step method
A doc string or a data tablethe parameter that it became
A tag, at each levelthe related @Tag annotation
Any cell of an Examples tablethe @CsvSource annotation, at the start of its CSV block

Two destinations for navigating from a step​

Cmd+Click or Ctrl+Click on a step opens the implemented step method.

Cmd+Shift+Click or Ctrl+Shift+Click opens the call of the step method. This is the line in the generated scenario test method that calls the step. For a background step, this line is in the @BeforeEach method. Thus you can see where the generated code calls the step.

The two clips below start from the same step, in the same file. Only the modifier differs.

From the code back to the spec file​

The same gestures operate in the opposite direction. From the generated test class you go to the Feature: line. From a @Nested class you go to its Rule:. From a @Test method you go to its Scenario:. From a @BeforeEach method you go to Background:. From a call of a step you go to the related step, with Cmd+Shift+Click or Ctrl+Shift+Click.

The plugin finds the correct element. Two scenarios with the same title go to the correct scenario. A step that occurs two times in a scenario goes to the occurrence that you clicked.
