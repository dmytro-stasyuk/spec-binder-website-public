Features

What the plugin adds to your IDE, one area per page.

FeatureWhat it covers
File extensionsChoosing which of .feature and .specb the plugin handles, and coexisting with the Cucumber plugin
Auto-recompile on saveRegenerating tests when you save a spec, so edit-and-run needs no separate build step
Editor supportSyntax highlighting, completion, folding, formatting, commenting, structure view and spell checking
Typed doc strings"""html, """json, """xml fences with language-aware highlighting, and inline HTML preview
NavigationJumping between a spec and the generated test class, and back again
Run and debugGutter run icons on Feature, Rule and Scenario, and breakpoints on Gherkin steps
Inline execution feedbackPass/fail icons, staleness handling, and the inline error panel with diff viewers
RefactoringFind Usages and Rename across specs and step methods
