Why it helps

Compile-time safety

Compile-time safety

Undefined steps become compiler errors, not runtime failures. Type inference catches parameter mismatches before tests run. No more surprise failures in CI.

Plain JUnit 5

Plain JUnit 5

Generated tests are standard JUnit 5 classes. Run individual scenarios in your IDE, set breakpoints, and debug without any framework indirection.

Feature-scoped steps

Feature-scoped steps

Step methods are scoped via standard Java inheritance — no global step catalog. Share state between steps using plain instance fields, no DI framework required.

Simple state management

Simple state management

Share data between steps using ordinary instance fields on your step class. No ScenarioContext, no @Before/@After lifecycle hooks, no dependency injection container — just plain Java state, scoped to the scenario.

Type-safe data tables

Type-safe data tables

Data tables in Gherkin are bound to typed Java objects at compile time. Column mismatches, missing fields, and type errors are caught by the compiler — never silently in CI.

TDD-friendly

TDD-friendly

Write a scenario, watch it fail to compile, implement the missing steps, watch it go green. The compile-time feedback loop fits naturally into red-green-refactor.
